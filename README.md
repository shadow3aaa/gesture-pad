# Gesture Pad

用手势操作电脑。

## 运行

```powershell
bun install
bun run assets       # 下载 MediaPipe 运行时和手部模型，第一次运行前要做
bun run live         # Gesture Pad
bun run annotator    # Gesture Annotator
```

## 手势

| 手势 | 怎么做 |
| --- | --- |
| 指向 | 只伸食指，拇指随意。光标在拇指和食指尖中间。 |
| 点击 / 拖动 | 拇指捏到食指上，捏住移动就是拖动。 |
| 滚动 | 伸出食指和中指上下划，内容跟着手走。 |
| 空闲 | 张开手掌、握拳、手放松，光标不动，骨架变淡。 |

加载模型后，空闲和划动交给模型判断。模型模式下滚动只往识别出的方向走，收手时不会滚回去。模型出错会自动退回规则。

`Esc` 停止控制，`Ctrl+Shift+Space` 在任何窗口停止控制。

## 训练模型

1. 打开 Gesture Annotator，选一个数据目录。录下的会话以 JSON 存在这里，只有手部关键点，没有视频。
2. **采集**：选一个动作（空闲、指向、上划、下划），倒计时后照提示做 10–60 秒。录指向时顺便点几下、拖几下，捏着的手也算指向。录完会按规则自动生成标签：空闲录制整段标空闲；指向录制里不是操作手势的帧标空闲；划动录制里只有朝提示方向的快速移动算划动，收手和停顿都算空闲。
3. **校对**：边回放骨架边改时间轴上的标签。划动录制里收手的那段最容易标错。改完勾上「已校对」再保存，没勾的不参与训练。
4. **训练**：点开始。每个会话最后 20% 留作验证，验证结果最好的一轮存到 `数据目录/model`，连续 10 轮没进步就自动停。训练中途也可以手动停，最好的那轮照样保留。

## 代码

- `crates/gesture-model`：数据格式、特征、ST-GCN、训练和推理，用 burn + CUDA。
- `apps/annotator`、`ui/annotator`：Gesture Annotator。自动标签在 `ui/annotator/lib/autolabel.ts`。
- `apps/live`、`ui/live`：Gesture Pad，包括透明置顶的骨架窗口、鼠标输出和模型推理。
- `ui/shared/hand.ts`：滤波、坐标映射、点击容差，以及规则和模型两套判断。
