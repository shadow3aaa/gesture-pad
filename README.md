# Gesture Pad

用普通摄像头把手变成鼠标。手的骨架画在屏幕最上层，你看着它指、点、拖、滚，不用校准。

仓库里有两个程序：

- **Gesture Pad**：控制鼠标。
- **Gesture Annotator**：录自己的手势、改标签、训练模型。

不加载模型时，手势全靠规则判断。规则有分不清的时候，比如上划之后把手收回来，看着就像一次下划，所以可以拿自己的数据训练一个小模型（ST-GCN）来判断空闲和划动。点击一直按拇指和食指的距离判断，跟模型无关。

只在 Windows 上用过。

## 运行

要装 Bun、Rust、Windows C++ Build Tools 和 WebView2。训练和使用模型还需要 NVIDIA 显卡和 CUDA，只用规则就不需要。

```powershell
bun install
bun run assets       # 下载 MediaPipe 运行时和手部模型，第一次运行前要做
bun run live         # Gesture Pad
bun run annotator    # Gesture Annotator
bun run dev          # 浏览器预览，只能用规则，也不会动鼠标
bun run build:desktop
```

## 手势

| 手势 | 怎么做 |
| --- | --- |
| 指向 | 只伸食指，拇指随意。光标在拇指和食指尖中间。 |
| 点击 / 拖动 | 拇指捏到食指上，捏住移动就是拖动。 |
| 滚动 | 伸出食指和中指上下划，内容跟着手走。 |
| 空闲 | 张开手掌、握拳、手放松，光标不动，骨架变淡。 |

几个细节：

- 灵敏度 2 的意思是画面中间一半对应整个屏幕。
- 捏下去之后，手抖动不超过屏幕的 1.2%，光标就不会动；松开后光标再停 150ms。这样点击时不会因为手抖变成拖动。
- 没有左右滚动。左右快速划的时候，摄像头经常跟丢手。

加载模型后，空闲和划动交给模型判断。模型模式下滚动只往识别出的方向走，收手时不会滚回去。模型出错会自动退回规则。

`Esc` 停止控制，`Ctrl+Shift+Space` 在任何窗口里都能停。手离开画面会立刻松开按键；后端 500ms 收不到数据也会自己停。

## 训练自己的模型

1. 打开 Gesture Annotator，选一个数据目录。录下的会话以 JSON 存在这里，只有手部关键点，没有视频。
2. **采集**：选一个动作（空闲、指向、上划、下划），倒计时后照提示做 10–60 秒。录指向时顺便点几下、拖几下，捏着的手也算指向。录完会按规则自动生成标签：空闲录制整段标空闲；指向录制里不是操作手势的帧标空闲；划动录制里只有朝提示方向的快速移动算划动，收手和停顿都算空闲。
3. **校对**：边回放骨架边改时间轴上的标签。划动录制里收手的那段最容易标错。改完勾上「已校对」再保存，没勾的不参与训练。
4. **训练**：点开始。每个会话最后 20% 留作验证，验证结果最好的一轮存到 `数据目录/model`，连续 10 轮没进步就自动停。训练中途也可以手动停，最好的那轮照样保留。
5. 回到 Gesture Pad。数据目录选的是仓库里的 `data` 的话，Gesture Pad 启动时会自动加载 `data/model`；放在别处的模型点「加载模型」选目录就行，下次启动会记住。点了「改用规则」也会记住，之后就不再自动加载。

模型文件不大，现在这个配置约 160 KB（4 万个参数）。

每类至少录两三段，最好分几次、换换坐姿和光线。模型只见过你的手和你的摄像头，换人或者换摄像头位置，都得补数据。

校对时的快捷键：

| 操作 | 按键 |
| --- | --- |
| 选一段 | 单击，或拖动框选；`Tab` / `Shift+Tab` 跳到下一段 / 上一段 |
| 设起点 / 终点 | `I` / `O` |
| 切一刀 | `S`（切在播放头上） |
| 边界 | 单击选中，拖动移动，`Del` 删除（合并后用左边那段的标签）；`[` `]` 跳到上一个 / 下一个边界 |
| 改标签 | `1`–`4`，`Del` 清除 |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Shift+Z` |
| 播放 | `空格`；`←` `→` 逐帧，按住 `Shift` 一次走 10 帧 |
| 缩放 | 滚轮缩放，`Shift`+滚轮平移，双击放大 |

很短的碎片可以点「清理碎片」，短于 150ms 的片段会并到旁边较长的那段。

## 模型

- 输入是最近 16 帧，大约半秒。每帧 21 个关节，每个关节 8 个数：以手腕为原点、按手长归一化的三维形状，形状的变化速度，以及手在画面里的移动速度。速度统一换算到 30fps，摄像头帧率不同也不影响。
- 网络是 3 层时空图卷积：空间上沿着手的骨架聚合相邻关节，时间上用长度 5 的因果卷积，只看过去的帧，不会增加延迟。输出 4 类：空闲、指向、上划、下划。
- 训练用 AdamW（权重衰减 0.01）、余弦学习率、0.2 的 dropout、按类别频率加权的交叉熵和 0.05 的标签平滑，数据增强是小角度旋转和速度缩放。
- 训练窗口里的准确率是先按类别分别算、再取平均，不然帧数最多的空闲会把数字撑高。

早期版本还有左划、右划、捏合三类。旧会话照常能打开：左右划的片段会被去掉，捏合的片段并入指向。旧模型加载不了，会提示重新训练。

## 代码

- `crates/gesture-model`：数据格式、特征、ST-GCN、训练和推理，用 burn + CUDA。
- `apps/annotator`、`ui/annotator`：Gesture Annotator。自动标签在 `ui/annotator/lib/autolabel.ts`。
- `apps/live`、`ui/live`：Gesture Pad，包括透明置顶的骨架窗口、鼠标输出和模型推理。
- `ui/shared/hand.ts`：滤波、坐标映射、点击容差，以及规则和模型两套判断。

```powershell
bun test tests
bun run build; bun run build:annotator
cargo test --workspace
cargo test -p gesture-model --test cuda -- --ignored   # 要 NVIDIA 显卡：训练、保存、加载、推理走一遍
```
